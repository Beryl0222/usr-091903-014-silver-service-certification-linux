# 银发服务体验认证

面向旅居、课程、康养等银发服务的**服务体验证据平台**。平台不把一次活动的满意度包装成长期质量，而是按真实人群分层留存可追溯、不可改写的体验证据，并据此给出有边界的认证。

## 平台规则

1. **先分层、经本人同意，再测试**。按四个维度固定分层：
   - 年龄阶段（低龄 60–69 / 中龄 70–79 / 高龄 80+）
   - 健康状况（健康 / 慢病稳定 / 行动受限 / 照护依赖）
   - 居住状态（独居 / 与家人同住 / 机构居住）
   - 辅助需求（无需辅助 / 使用辅具 / 需人员陪护）

   每次采集记录所依据的同意协议版本；同意撤回后旧证据保留但立即失效，不得删除或改写。低龄健康者试用良好，不能证明独居、行动受限或慢病人群也能安全完成。

2. **证据记录五类事实**：关键任务完成情况、可达性障碍（含严重程度）、人员响应（响应时长/评价）、价格披露程度、中途退出及原因。每条证据附**逐字原始反馈**，一经写入只能追加附注，供应商无权改写；所有写入进入 SHA-256 哈希链，并可逐条比对证据与上链内容。

3. **方案/场地版本化管理**。方案按"面"声明（场地、课程内容、康养人员、价格、交通接驳）。新版本登记变更面后，平台只复用依赖面未受影响的证据，并给出必须复测的**分层×能力单元**清单。

4. **代表性覆盖评审**。每个拟覆盖分层至少 3 名参与者，且每个"分层×已验证能力"单元要有完成关键任务的证据。覆盖不足、声称范围超出证据一律驳回；关键（critical）障碍**不可豁免**，例外只能整体缩小适用人群范围并全程留痕。

5. **严重事件立即暂停相关等级**，不必等待整改。供应商提交整改、认证人员复验通过后才恢复；复验失败继续暂停。暂停期间同等级新评审一律驳回。

6. **申诉回避**：对暂停措施或驳回决定的申诉，必须由**未参与原评审、未上报该事件**的认证人员处理。

7. **三视图，信息严格分层**：
   - 消费者：适用人群、有效期、已验证能力、暂停提示；
   - 企业：仅本企业服务的**脱敏缺陷清单**（障碍计数、价格披露、退出率、平均响应时长），不含任何参与者标识与逐字反馈；
   - 认证人员：从等级追溯到方案版本链、证据复用关系、代表性覆盖、例外决定、事件、整改复验、申诉与完整性校验。

## 运行

```bash
python3 service.py --check          # 配置自检
python3 service.py --port 8000      # 启动服务，GET /health 确认身份
npm test                            # 运行全部 32 个测试
```

服务仅用 Python 标准库，无外部依赖；数据为进程内存储，重启清空（联调用）。

## HTTP 接口

所有写接口的请求体都带 `actor: {id, role}`，角色为 `tester` / `certifier` / `provider`。`GET /reference` 返回分层与方案面的合法取值词表。

| 方法 & 路径 | 角色 | 说明 |
| --- | --- | --- |
| `POST /participants` | tester | 登记分层与本人当次同意 |
| `POST /participants/{id}/withdraw` | tester | 撤回同意（证据失效但保留） |
| `POST /plans` | provider | 登记方案版本与方案面 |
| `POST /plans/{id}/versions` | provider | 基于变更面登记新版本 |
| `GET  /plans/{id}/reuse` | — | 可复用证据 / 必须复测单元 |
| `POST /evidence` | tester | 采集证据（含逐字原始反馈） |
| `POST /evidence/{id}/amend` | tester | 追加更正附注，不改原文 |
| `POST /certifications/decide` | certifier | 代表性覆盖评审与例外决定 |
| `POST /incidents` | 三种角色 | 上报严重事件，立即暂停相关等级 |
| `POST /rectifications` | provider | 提交整改措施 |
| `POST /reverifications` | certifier | 复验（通过后恢复） |
| `POST /appeals` | provider | 对暂停（`cert_id`）或驳回（`decision_id`）申诉 |
| `POST /appeals/{id}/decide` | certifier | 独立人员裁决（原评审人 403 回避） |
| `GET  /views/consumer` | — | 消费者视图 |
| `POST /views/enterprise` | provider | 企业脱敏缺陷清单 |
| `GET  /certifications/{id}/trace` | — | 认证人员全链路追溯 |

领域规则独立于 HTTP，集中在 `evidence_platform.py`，可直接在其他入口（批处理、定时到期检查等）复用。
